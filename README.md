# pep talk

记录你的成功案例。下一次那种感觉来时，它们会告诉你：你曾经成功过。

## 在线访问

https://sylviaooo2026.github.io/pep-talk/

## 本地开发

```bash
npm install
npm run dev
```

开发地址：`http://localhost:5173/pep-talk/`（与 GitHub Pages 使用同一路径前缀）

## 脚本

- `npm run dev` — 本地开发
- `npm test` — 测试
- `npm run build` — 生产构建
- `npm run preview` — 预览构建结果
